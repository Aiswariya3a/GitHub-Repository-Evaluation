<objective>
Fix the PDF report generation pipeline by refactoring pdf_gen.py from a standalone CLI script into a callable module.

Purpose: Eliminate the fragile subprocess-based PDF generation that fails silently and cannot propagate errors to the UI. The current design runs `pdf_gen.py` via `subprocess.run()` which triggers top-level code execution, uses its own service instances bypassing the DI container, and provides no error feedback path.

Output:
- `pdf_gen.py` refactored to expose `generate_pdf(session_id, output_dir)` function
- `services/report_service.py` imports `pdf_gen.generate_pdf()` directly
- Error messages from failures surface as Flask flash messages in the UI
</objective>
