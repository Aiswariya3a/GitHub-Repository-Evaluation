Create `services/ollama_client.py` with the following:

**OllamaClient class:**
- Constructor reads `OLLAMA_HOST` (default `http://localhost:11434`) and `OLLAMA_PORT` (default `11434`) from environment variables (OLL-01). Builds `base_url` as `{OLLAMA_HOST}:{OLLAMA_PORT}`.
- Constructor also configures model routing map per OLL-02 and OLL-03:
  ```python
  self._model_map = {
      "code": os.getenv("OLLAMA_CODE_MODEL", "qwen2.5-coder:3b"),
      "reasoning": os.getenv("OLLAMA_REASONING_MODEL", "phi-4-mini:3.8b"),
  }
  ```
- `validate_connectivity() -> dict` method (OLL-04):
  - GET `{base_url}/api/tags` to list available models
  - Check both required models exist in the response
  - Return `{"connected": True, "available_models": [...], "missing_models": [...]}`
  - On connection error, raise `OllamaConnectionError` with clear message instructing to start Ollama
  - On missing model, raise `OllamaModelNotFoundError` with clear message to run `ollama pull <model>`
- `infer(model_role: str, system_prompt: str, user_prompt: str, temperature: float = 0.0, format: Optional[str] = None) -> dict` method (OLL-05):
  - `model_role` is either `"code"` or `"reasoning"` — routes to the appropriate model
  - Enforces `temperature=0` — if caller passes non-zero, log warning but use 0 (OLL-05)
  - POST `{base_url}/api/generate` with `{"model": ..., "system": ..., "prompt": ..., "temperature": 0, "stream": false, "format": format}`
  - If `format="json"` is passed, include it in the request body (Ollama's structured output mode)
  - Parse and return `response.json()["response"]` for plain or try `json.loads(response)` for JSON format
  - Wrap HTTP errors in `OllamaAPIError` with status code and response body
  - Timeout: 300 seconds default, configurable via `OLLAMA_TIMEOUT` env var

**Custom exceptions:**
- `class OllamaConnectionError(Exception)` — connection failures
- `class OllamaModelNotFoundError(Exception)` — model not pulled
- `class OllamaAPIError(Exception)` — API response errors

**Entry point guard:**
```python
if __name__ == "__main__":
    import sys
    client = OllamaClient()
    result = client.validate_connectivity()
    if result["connected"]:
        print(f"Ollama connected. Models: {result['available_models']}")
        if result["missing_models"]:
            print(f"WARNING: Missing models: {result['missing_models']}", file=sys.stderr)
            sys.exit(1)
    else:
        print("ERROR: Cannot connect to Ollama", file=sys.stderr)
        sys.exit(1)
```

Do NOT use the `ollama` Python package — make raw HTTP calls to avoid dependency issues (research found SLM JSON output instability; direct HTTP gives more control). Do NOT add any caching layer. Do NOT implement retry logic here (orchestrator handles retries per ORC-03).

**BaseAgent abstract class (per D-01):**
```python
from abc import ABC, abstractmethod
from typing import Optional
from services.ollama_client import OllamaClient

class BaseAgent(ABC):
    """All agents inherit from BaseAgent and implement `run()`.
    
    Default execution is in-process (D-01). Subprocess mode available
    via config flag (D-02).
    """
    
    def __init__(self, ollama_client: Optional[OllamaClient] = None, 
                 execution_mode: str = "in_process"):
        self.ollama = ollama_client or OllamaClient()
        self.execution_mode = execution_mode  # "in_process" or "subprocess"
    
    @abstractmethod
    def run(self, input_data: dict, output_path: Optional[str] = None) -> dict:
        """Execute agent logic.
        
        Args:
            input_data: Input dict (e.g., ProjectSnapshot slice for capability agents)
            output_path: If provided, agent writes validated output to this path (D-11)
        Returns:
            dict: Agent output (capability extraction, evaluation, or feedback)
        """
        ...
    
    def _write_output(self, output: dict, output_path: str) -> None:
        """Write validated output JSON to file (idempotent per D-11)."""
        import json, os
        os.makedirs(os.path.dirname(output_path), exist_ok=True)
        with open(output_path, "w") as f:
            json.dump(output, f, indent=2, default=str)
    
    def _validate_output(self, output: dict, schema: dict) -> tuple[bool, list[str]]:
        """Validate output dict against JSON Schema. Returns (valid, errors)."""
        import jsonschema
        try:
            jsonschema.validate(instance=output, schema=schema)
            return True, []
        except jsonschema.ValidationError as e:
            return False, [str(e)]
```
