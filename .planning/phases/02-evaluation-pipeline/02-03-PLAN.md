Build the Rubric Evaluation subsystem — loads rubrics from PostgreSQL, routes evidence to criteria, evaluates each criterion independently via SLM, and aggregates scores deterministically.

**Purpose:** The rubric evaluation engine is the core scoring mechanism. It ensures every rubric criterion receives a focused evaluation using only the evidence that matters for that criterion, with scores clamped to rubric limits and aggregated without LLM involvement.

```python
"""Maps rubric criteria categories to relevant Project Snapshot sections.

The orchestrator uses this to pre-filter evidence before passing to the
Rubric Evaluation Agent, reducing token usage and focusing the SLM.
"""

from models.ingestion_models import ProjectSnapshot


# Category -> evidence section mapping (D-04)
# Extensible — add new mappings as rubric designs evolve
EVIDENCE_ROUTING_MAP = {
    "code_understanding": ["files[].functions", "files[].imports", "repo_stats"],
    "collaboration": ["github_metadata"],
    "repository": ["repo_stats", "files[]", "repository_metadata"],
    "implementation": ["files[].functions", "files[].classes", "delta"],
    "documentation": ["files[].docstrings", "files[].comment_ratio"],
    "testing": ["files[].functions", "files[].imports"],
    "error_handling": ["files[].functions", "files[].imports"],
    "structure": ["repo_stats", "files[]", "delta"],
}


def route_evidence(snapshot: dict, criterion_category: str) -> dict:
    """Extract relevant evidence from snapshot based on criterion category.
    
    Args:
        snapshot: ProjectSnapshot as dict
        criterion_category: Category code from rubric (e.g., 'Q1A', 'Q2B')
        
    Returns:
        Subset of snapshot with only relevant sections for this criterion.
    """
    category_lower = criterion_category.lower()
    
    # Find best matching routing key
    routing_key = None
    for key in EVIDENCE_ROUTING_MAP:
        if key in category_lower or category_lower in key:
            routing_key = key
            break
    if not routing_key:
        routing_key = "implementation"  # sensible default
    
    evidence_sections = EVIDENCE_ROUTING_MAP[routing_key]
    return _filter_snapshot(snapshot, evidence_sections)


def _filter_snapshot(snapshot: dict, sections: list[str]) -> dict:
    """Filter snapshot to only include specified sections."""
    result = {}
    for section in sections:
        parts = section.split(".")
        current = snapshot
        valid = True
        for part in parts:
            if isinstance(current, dict) and part in current:
                current = current[part]
            else:
                valid = False
                break
        if valid:
            _set_nested(result, parts, current)
    return result


def _set_nested(d: dict, keys: list[str], value) -> None:
    """Set value in nested dict using key path."""
    current = d
    for key in keys[:-1]:
        if key not in current:
            current[key] = {} if key != keys[-2] else []
        current = current[key]
    if keys:
        current[keys[-1]] = value
```

The mapping must be extensible — new categories can be added with a simple dict entry. The `route_evidence` function does fuzzy matching so criteria codes like "Q1A", "Q2B" that don't literally contain mapping keys still match a sensible default.

```python
You have been provided with:
- A rubric criterion to evaluate (criterion_key, name, max_score)
- Evidence extracted from the student's repository (functions, imports, metrics, etc.)
- The overall repository context (language, file count, complexity)

Your task:
1. Evaluate ONLY the specific criterion using ONLY the provided evidence
2. Assign a score between 0 and max_score (inclusive)
3. Provide a confidence level (0-1) indicating how certain you are
4. List specific evidence items that support your score
5. Write concise, constructive remarks

Rules:
- Be strict but fair — base scores on demonstrated capability
- If evidence is insufficient, score low and note it in remarks
- Confidence < 0.5 means the evidence was unclear or contradictory
- NEVER exceed max_score
- Output ONLY valid JSON matching the schema."""
```

```python
"""Deterministic score aggregation — no LLM involved in arithmetic (EVA-06)."""

from dataclasses import dataclass, field
from typing import Optional
from models.evaluation_models import CriterionEvaluation, CategoryScore, AggregatedScore


def aggregate_scores(
    criteria_results: list[dict],
    rubric_version: dict,
) -> AggregatedScore:
    """Aggregate individual criterion evaluations into final scores.
    
    Args:
        criteria_results: List of validated criterion evaluation dicts
            (each validated against CRITERION_EVALUATION_SCHEMA)
        rubric_version: Rubric version dict from RubricRepository.get_version()
            with categories[].criteria[] structure
    
    Returns:
        AggregatedScore with total, normalized, percentage, per-category breakdown
    """
    # Build lookup: (category_code, criterion_key) -> result
    result_map = {}
    for cr in criteria_results:
        result_map[(cr["category_code"], cr["criterion_key"])] = cr
    
    categories_list: list[CategoryScore] = []
    total_score = 0.0
    max_score_total = 0.0
    low_conf_criteria: list[str] = []
    
    for category in rubric_version["categories"]:
        cat_code = category["code"]
        cat_name = category["name"]
        cat_max = float(category["max_score"])
        max_score_total += cat_max
        
        criteria_list: list[CriterionEvaluation] = []
        cat_total = 0.0
        
        for criterion in category["criteria"]:
            key = criterion["criterion_key"]
            crit_max = float(criterion["max_score"])
            result = result_map.get((cat_code, key))
            
            if result:
                score = float(result["score"])
                confidence = float(result.get("confidence", 0))
                # Clamp to rubric maximum (EVA-07)
                score = max(0.0, min(score, crit_max))
                
                if result.get("confidence_warning", False) or confidence < 0.5:
                    low_conf_criteria.append(f"{cat_code}.{key}")
                
                criteria_list.append(CriterionEvaluation(
                    criterion_key=key,
                    category_code=cat_code,
                    score=score,
                    max_score=crit_max,
                    confidence=confidence,
                    evidence=result.get("evidence", []),
                    remarks=result.get("remarks", ""),
                    confidence_warning=(confidence < 0.5),
                ))
            else:
                # Missing criterion — score 0
                low_conf_criteria.append(f"{cat_code}.{key}")
                criteria_list.append(CriterionEvaluation(
                    criterion_key=key,
                    category_code=cat_code,
                    score=0.0,
                    max_score=crit_max,
                    confidence=0.0,
                    evidence=[],
                    remarks="Criterion was not evaluated",
                    confidence_warning=True,
                ))
            
            cat_total += criteria_list[-1].score
        
        total_score += cat_total
        cat_total = max(0.0, min(cat_total, cat_max))  # Clamp category total
        
        categories_list.append(CategoryScore(
            category_code=cat_code,
            category_name=cat_name,
            total_score=round(cat_total, 2),
            max_score=cat_max,
            criteria=criteria_list,
        ))
    
    # Normalize to 20 (standard for this platform)
    normalized = (total_score / max_score_total * 20) if max_score_total > 0 else 0
    percentage = (total_score / max_score_total * 100) if max_score_total > 0 else 0
    
    return AggregatedScore(
        total_score=round(total_score, 2),
        max_score=round(max_score_total, 2),
        normalized_to_20=round(normalized, 2),
        percentage=round(percentage, 2),
        categories=categories_list,
        low_confidence_criteria=low_conf_criteria,
    )
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PostgreSQL → RubricEvaluationAgent | Rubric data loaded from DB; incorrect rubric loads could skew scores |
| Evidence Router → Agent | Pre-filtered snapshot may omit critical evidence for a criterion |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | Rubric data from PostgreSQL | accept | Rubrics managed by authorized users; no public write access |
| T-02-02 | DoS | Parallel criterion evaluation | mitigate | max_parallel_agents configurable; ThreadPoolExecutor bounds concurrency |
| T-02-03 | Tampering | CRITERION_EVALUATION_SCHEMA validation bypass | mitigate | Score clamping in aggregator is final defense — even if invalid scores pass schema, they get clamped |
| T-02-04 | Spoofing | Missing criterion silently scored 0 | mitigate | Missing criteria are logged in low_confidence_criteria; visible to reviewers |
</threat_model>
