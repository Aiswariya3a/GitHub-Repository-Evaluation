All 5 agents extend BaseAgent (services/evaluation/agent_base.py):
```python
class BaseAgent(ABC):
    def __init__(self, ollama_client=None, execution_mode="in_process"):
        self.ollama = ollama_client or OllamaClient()
    
    @abstractmethod
    def run(self, input_data: dict, output_path=None) -> dict: ...
```

Each agent has a SYSTEM_PROMPT constant and calls self.ollama.infer():
- RepoUnderstandingAgent: ollama_router.REPO_UNDERSTANDING_SYSTEM_PROMPT → model_role="code"
- CodeUnderstandingAgent: ollama_router.CODE_UNDERSTANDING_SYSTEM_PROMPT → model_role="code"
- CollaborationAgent: ollama_router.COLLABORATION_SYSTEM_PROMPT → model_role="code"
- RubricEvaluationAgent: RUBRIC_EVALUATION_SYSTEM_PROMPT → model_role="reasoning"
- FeedbackAgent: FEEDBACK_SYSTEM_PROMPT → model_role="reasoning"

OllamaClient.infer() signature:
```python
def infer(self, model_role: str, system_prompt: str, user_prompt: str, temperature: float = 0.0, format=None) -> dict
```

    ```python
    def test_agent_run(self, mock_ollama_client, sample_snapshot):
        # Arrange
        mock_response = json.dumps({...expected output matching schema...})
        mock_ollama_client.infer.return_value = {"response": mock_response}
        
        agent = RepoUnderstandingAgent(ollama_client=mock_ollama_client)
        
        # Act
        result = agent.run(sample_snapshot)
        
        # Assert
        jsonschema.validate(instance=result, schema=REPO_UNDERSTANDING_SCHEMA)
        assert "languages" in result
    ```
